## ✨ Why OpenAll-In-AI?

> **"Stop juggling 10 different AI tools. Everything you need, in one free, private, local toolbox."**

OpenAll-In-AI is the **Swiss Army Knife** of AI tools — combining the power of large language models, AI image generation, OCR, document parsing, code generation, audio/video processing, and PDF tools into a single, beautiful, privacy-first application.

### 🎯 Perfect For Everyone

| User Type | How It Helps |
|-----------|--------------|
| 👨‍🎨 **Students** | AI study assistant, exam analyzer, note summarizer |
| 👩‍💼 **Professionals** | Smart PDF tools, document automation, meeting transcription |
| 👨‍💻 **Developers** | Code generation, debugging, scaffolding, API testing |
| 📱 **Content Creators** | AI image generation, video subtitles, voiceover, OCR |

### 💎 Key Features That Set Us Apart

- 🔒 **100% Private** — All processing happens locally. Your data never leaves your machine.
- ⚡ **Zero Config** — Download, double-click, and go. No Python setup, no CUDA, no API keys needed.
- 🦊 **Lightweight** — Runs smoothly on 8GB RAM laptops with local models.
- 🌍 **Multi-Platform** — Windows, macOS, Linux, and the Web. One codebase, all devices.
- 🔌 **Plugin System** — Extend functionality with our open SDK. Build your own AI tools.
- 🎨 **Beautiful UI** — Modern, responsive, dark-mode-ready interface.

### Option 2: Run from Source

```bash
# 1. Clone the repository
git clone https://github.com/luo1chen/OpenAll-In-AI.git
cd OpenAll-In-AI

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start the server
python main.py
```

Open your browser and visit **`http://localhost:8000`** 🎉

### Option 3: Docker One-Liner

```bash
docker run -p 8000:8000 openall-in-ai
```

## 🏗️ Technical Architecture

```
┌─────────────────────────────────────────────────┐
│                   Frontend                      │
│         Vue 3 + Element Plus + Pinia             │
├─────────────────────────────────────────────────┤
│                   Backend                        │
│    FastAPI + SQLAlchemy + WebSockets              │
├─────────────────────────────────────────────────┤
│              AI Engine Layer                     │
│   llama.cpp │ Cloud APIs │ Plugin System          │
├─────────────────────────────────────────────────┤
│                   Storage                        │
│              SQLite + Local File System           │
└─────────────────────────────────────────────────┘
```

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Frontend | Vue 3 + Element Plus | Beautiful, responsive UI |
| Backend | Python FastAPI | High-performance async API |
| AI Engine | llama.cpp | Local LLM inference |
| Database | SQLite | Lightweight data persistence |
| Packaging | PyInstaller | Cross-platform executables |
| Testing | pytest | Comprehensive test coverage |

## ⚙️ Configuration

### Cloud API Setup (Optional)

OpenAll-In-AI works perfectly with local models, but you can also connect cloud APIs in **Settings → API Config**:

| Provider | Models Supported |
|----------|-----------------|
| OpenAI | GPT-3.5-Turbo, GPT-4, GPT-4o |
| Alibaba Tongyi | Qwen-Turbo, Qwen-Max, Qwen-Plus |
| iFLYTEK Spark | Spark 1.5, Spark Max |
| DeepSeek | DeepSeek Chat |

### System Requirements

| Tier | CPU | RAM | Storage |
|------|-----|-----|---------|
| Minimum | 4 cores | 8 GB | 10 GB |
| Recommended | 8+ cores | 16 GB+ | 20 GB+ |
| Pro | 12+ cores | 32 GB+ | 50 GB+ (SSD) |

GPU: Optional (NVIDIA 4GB+ recommended for local image generation)

## 🔧 Development

```bash
# Clone & setup
git clone https://github.com/luo1chen/OpenAll-In-AI.git
cd OpenAll-In-AI

# Virtual environment
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt
cd frontend && npm install

# Start development servers
# Terminal 1: Backend
python main.py

# Terminal 2: Frontend
cd frontend && npm run dev
```

### Testing

```bash
# Backend tests
pytest tests/ -v

# Coverage report
pytest --cov=backend --cov-report=html
```
